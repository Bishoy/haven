# Weather Icons

These PNG files are sourced from Met Eireann weather symbols and mapped to HAven condition filenames.

- Symbol reference page: https://www.met.ie/forecasts/weather-symbols
- Runtime files: `clear-day.png`, `rain.png`, `rain-night.png`, etc.

Notes

- Day/night selection in the weather widget uses forecast `datetime` and picks `*-night.png` variants when available.
- Legacy Meteocons license file is kept as-is for historical reference of previous assets.
